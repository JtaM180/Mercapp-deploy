El frontend se despliega como SPA estática en Netlify. Las peticiones al API van al backend en Railway via HTTPS con CORS restringido al dominio de Netlify.

💻 Ejecución Local

Backend

cd backend
npm install
npm run dev       # puerto 3000

Frontend

cd frontend
npm install
# Crear archivo .env con:
# VITE_API_URL=http://localhost:3000
npm run dev       # puerto 5173

📡 Endpoints de la API

MétodoRutaDescripciónEjemplo Response
GET /health Health check del servidor {"status":"ok"}
GET /api/products Listar todos los productos [{id, name, price, ...}]
GET /api/products/:id Obtener un producto por ID {id, name, price, stock, ...}
POST /api/products Crear nuevo producto {id, name, price, ...} (201)
PUT /api/products/:id Editar producto existente {id, name, price, ...}
DELETE /api/products/:id Eliminar producto {"message":"Producto eliminado"}
GET /api/categories Listar categorías [{id, name}]
